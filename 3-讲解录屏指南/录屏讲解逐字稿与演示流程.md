## 💡 应对老师随机抽问的标准答辩要点（速查手册）

| 老师可能提问的问题 | 标准应效应答思路（胸有成竹） | 代码所在文件 |
| :--- | :--- | :--- |
| **Q1：你的页面间传值是怎么实现的？** | 答：“在 MainActivity 中使用显式 Intent：`Intent intent = new Intent(this, LedgerDetailActivity.class)`，通过 `intent.putExtra("KEY", value)` 压入基本数据类型和字符串；在目标 Activity 的 `onCreate` 中通过 `getIntent().getStringExtra()`、`getDoubleExtra()` 等方法解析并展示。” | `MainActivity.java` (L180-L198) |
| **Q2：ListView 和 Adapter 的工作原理是什么？** | 答：“ListView 采用了 MVC 模式，数据源通过继承 `BaseAdapter` 的自定义 `RecordAdapter` 绑定到视图上。重写了四个核心方法：`getCount()` 返回数据长度，`getView()` 加载每行的 item 布局并填充数据。同时采用了静态 `ViewHolder` 缓存控件引用，复用 `convertView`，大幅降低 `findViewById` 开销，避免滚动卡顿。” | `RecordAdapter.java` (L45-L85) |
| **Q3：你的姓名学号是在哪里写死的？** | 答：“在 `activity_main.xml` 和 `activity_ledger_detail.xml` 的顶部均放置了专用的 `TextView`，绑定了 `strings.xml` 与常量。并且设置了 `focusable=false` 与 `clickable=false`，程序在运行时绝不可被编辑或修改。” | `activity_main.xml` (L38-L51)<br>`strings.xml` (L4-L8) |
| **Q4：你是如何防范金额输入闪退的？** | 答：“通过 `TextUtils.isEmpty(amountStr)` 进行非空拦截，并使用 `try-catch` 捕获 `NumberFormatException`；若金额小于等于0，调用 `etAmount.setError()` 高亮警示并中断执行，防止程序崩溃闪退。” | `MainActivity.java` (L130-L155) |
